Charge USDC per API call.
No Stripe. No accounts.

usdc-paywall turns any Node.js endpoint into a paid API with an x402-style HTTP 402 flow. Clients pay USDC on Base; you verify the transaction on-chain. Zero dependencies.

⚡ HTTP 402 native

Unpaid requests get 402 + payment instructions. Paid tx-hash gets verified on-chain, then served.

🔒 On-chain truth

Reads USDC Transfer events from Base RPC. No facilitator, no custody, no third party between you and your funds.

📦 Zero-dep install

npm i usdc-paywall — Node 18+, no native builds, works on ARM and Raspberry Pi.

🛠 CLI included

One command to verify a payment from shell scripts, CI, or other agents.

import { paywall } from 'usdc-paywall';

app.use('/api/premium', paywall({
  price: '0.50',          // USDC per call
  wallet: '0xYourWallet',   // where clients pay
  rpc: 'https://mainnet.base.org'
}));
// unpaid → 402 · valid tx-hash → 200 + your data
